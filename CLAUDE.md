# Working in this repo

Research program: humans and machines working in the same space because both can see the same thing.

## Keep the design journal

[Seeing systems design journal](https://claude.ai/artifact/88e7a541-1b9c-49d6-85f3-d7ee56581363) is the running
record. It is a Claude Docs doc: read and edit it with the docs connector, never by publishing files into it.
Write numbers from experiments straight into it and into any other doc this program creates.

Add to it as the work happens, not at the end:

- **Decision log** (table, newest first): every decision that changes the design, scope, models, spend or
  interpretation. Date, decision, why, and who made it (Jono, or Claude, or Claude proposed and Jono approved).
- **Experiment register**: one row per experiment, its question, status and one-line result.
- **Documents and references**: every new doc, results file or artifact, with a link.
- **Dated entries**: one when an experiment starts (what we are trying to learn, the embarrassment test),
  one when it finishes (results with numbers, what it taught us), and one whenever something changes course.
- **What we do next**: the recommendation, decisions waiting on Jono as checkboxes, open questions.

Program doc: [Seeing systems for humans and machines](https://claude.ai/artifact/NTc95ve9kfXJjr9UvAjBrJ).
Each experiment also keeps its own README (decisions taken alone), NOTES.md (parking lot, observations) and
STATUS.md in its directory.

## Running experiments

- Experiment 1 lives in `seeing-exp1/`; see its README. Python venv: `seeing-exp1/.venv`
  (`pip install -r seeing-exp1/requirements.txt`).
- Keys come from the cloud environment's variables: `SEEING_ANTHROPIC_API_KEY` (cloud environments reserve
  `ANTHROPIC_API_KEY` for Claude Code's own login) and `OPENAI_API_KEY`. Never write keys into files.
- Every result comes from a logged, seeded run in `results/runs/`; tables are generated by script, never
  typed. Spend is capped at $100 per experiment in `config.py`; raising it needs Jono.

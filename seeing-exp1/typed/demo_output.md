# 1d's five breaks, written in the vocabulary

## door, the 1d break as written in MJCF: range (0, 2.1) with no unit: does not compile

```
1 problem in this world. Nothing was built.

-- ANGLE WITHOUT A UNIT ----------------------------- Door.hinge.range[1]

I was expecting an angle, like deg(120) or rad(2.09), but I found:

    2.1

A bare number can't say whether it is degrees or radians. MuJoCo reads joint ranges in degrees but keyframe angles in radians, so 2.1 meant as radians becomes a 2.1 degree limit, and a door opened to 69 degrees starts outside it and snaps shut.

Hint: write deg(120) or rad(2.09)

```

```
MuJoCo would push it back inside its limit in the first few steps: whatever it was meant to do from there, it would not.

Hint: widen the range or change where it starts

```
